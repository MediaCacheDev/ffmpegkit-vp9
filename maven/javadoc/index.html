ffmpegkit-vp9

This artifact is FFmpegKit 6.0 (com.arthenica.ffmpegkit) with a reduced FFmpeg build: Matroska/WebM demuxing, VP9 decoding through libvpx (which keeps the alpha channel), and rawvideo output over the file and pipe protocols. Its Java API is unchanged; see the FFmpegKit Android documentation.

Build scripts, notices and source: github.com/MediaCacheDev/ffmpegkit-vp9.
